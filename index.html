Independent Research

Quantum Research

Published · April 2026 · Zenodo

Communication Complexity of the LWE Function:
First Exact Bounds and the Hard Distribution Structure

First formal study of the communication complexity of the Learning With Errors (LWE) function — the mathematical core of NIST post-quantum standards ML-KEM (FIPS 203) and ML-DSA (FIPS 204). Defines the LWE Communication Problem (LWE-CCn), proves lower bounds, computes the first exact values of rank, fooling sets, and discrepancy for small parameters, and identifies the hard distribution structure via coordinate-descent LP. Also defines QV-CCN,k — a new multiparty CC problem from QuantumMail-v2's quorum vault recovery — and proves its classical complexity exactly.

First CC analysis of any NIST PQC protocol
4 proved theorems
rank ∈ {31, 53, 126} — never published before
Fooling sets ≥ {104, 114, 173}

Nights of Work
📐
Theorem 1 — Proved
CC¹(LWE-CCn) ≥ n log₂ q bits. First rigorous lower bound for the communication complexity of any LWE-based protocol.
🔬
Theorem 2 — Computed Exactly
First exact CC bounds for LWE. rank(Mf) ∈ {31, 53, 126} and fooling sets ≥ {104, 114, 173} — values that do not appear in any prior publication.
⚡
Theorem 3 — Key Structural Finding
Hard distribution μ* concentrates on s=0 (reduces to INDEX, no quantum advantage). This localises the quantum-classical separation to s≠0 inputs — where VSP geometry is active.
🔗
Connection to ML-KEM
ML-KEM-768 key encapsulation (n=256, q=3329) is an instance of LWE-CC256. If Q¹ = O(log n) holds, quantum channels could reduce 1088-byte ciphertexts to ~8 qubits.
🏛️
QV-CC — New Problem Defined
QV-CCN,k: first multiparty CC problem from a deployed PQC protocol. Derived from QuantumMail-v2's quorum vault recovery. Classical complexity proved: D = Θ(k log p).
🎯
Main Conjecture — Open
Q¹(LWE-CCn) = O(log n) and R¹(LWE-CCn) = Ω(n1/3). This would be the first exponential quantum-classical CC separation for an LWE-based protocol. Working on it.
