Communication Complexity of the LWE Function:
First Exact Bounds and the Hard Distribution Structure

First formal study of the communication complexity of the Learning With Errors (LWE) function — the mathematical core of NIST post-quantum standards ML-KEM (FIPS 203) and ML-DSA (FIPS 204). Defines the LWE Communication Problem (LWE-CCn), proves lower bounds, computes the first exact values of rank, fooling sets, and discrepancy for small parameters, and identifies the hard distribution structure via coordinate-descent LP.

First CC analysis of any NIST PQC protocol 4 proved theorems rank ∈ {31, 53, 126} Fooling sets ≥ {104, 114, 173} Discrepancy + LP bounds computed 7 open problems identified
